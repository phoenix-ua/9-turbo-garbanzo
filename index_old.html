⚡ TechEscape: Експрес-Квест

Обирай 1 із 3 задач на свій вибір. Відкривай Google Docs та вирішуй проблему!

Рівень 1: Простий (Рятівник форматів)

Завдання «Хаос у видавництві»

Автор надіслав документ, але шрифт «поплив», а зображення зникли, бо файл зберегли у звичайному блокноті (.txt). Тобі потрібно з'ясувати, який формат розв'яже цю проблему.

📁 Відкрити документ №1 у Google Docs

Запитання: У який формат слід перезберегти документ, щоб він виглядав однаково на всіх смартфонах та ПК, зберігаючи всі елементи оформлення?

Рівень 2: Середній (Детектив об'єктів)

Завдання «Знайди помилку в оформленні»

У тексті статті порушено форматування: заголовок зливається з абзацами, а міжрядковий інтервал занадто великий.

📁 Відкрити документ №2 у Google Docs

Запитання: Назви 2 властивості об'єкта «Абзац» та 1 властивість об'єкта «Символ», які потрібно змінити для виправлення документа.

Рівень 3: Профі (Майстер режимів)

Завдання «Синхронне порівняння»

У тебе є дві версії документа. Потрібно знайти відмінності в тексті без виснажливого перемикання між файлами.

📁 Відкрити документ №3 у Google Docs

Запитання: Які функції або режими перегляду в текстово процесорі дозволяють бачити два фрагменти або два документи одночасно поруч?
